In every comment and review body on a repo whose owner `release-owners.json` lists, write "ship" or "publish step" where "release" would go, since an owner comment holding the word publishes to npm there.
The `no-release-comment` hook refuses the word for a session it guards, and every brief carries the rule for a session it does not (`scripts/hooks/README.md`).
Done when the body you post holds the word in no case.
