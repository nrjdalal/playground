Every word to the owner, an Inbox item or a dispatcher's reply in chat, Slack or Yard, takes to-inbox's shape: a picture, emoji bullets, plain ASD-STE100 words, one callout at most, IST times.
The owner reads each message in seconds, on whichever surface it lands, so one shape everywhere lets the point land first and every session read like every other.
to-inbox (`extensions/core/skills/to-inbox/SKILL.md`) is the shape's one source: its steps, its pictures, its emoji legend and the card width a drawing fits; load it with the Skill tool before you write to the owner.
A message outside the Inbox takes every step but the card's own Choices and Post, and a relay of a session's message to the owner is one such message.
How a session is named to the owner and the order PR status goes in stay in **voice**.
Done when every message you sent the owner leads with its picture, keeps each code line within the card's 60 columns (to-inbox's Fit the card), and passes to-inbox's plain-words check.
